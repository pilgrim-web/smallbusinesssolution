# Agent guidance

## Project contract

- Preserve strict TypeScript, RLS, append-only `time_events`, append-only `audit_logs`, and database uniqueness constraints.
- Payroll timestamps are generated by the server and stored as `timestamptz` (UTC). Browser time is display-only.
- Employee identity comes from the hashed employee-session token, never request-supplied employee or company IDs.
- Never log PINs, PIN hashes, raw session tokens, or precise location payloads.
- Location capture is event-based only. Never add background or continuous tracking.
- Every manager edit requires a reason, immutable event, and audit record containing original values.
- Production routes must use `lib/data` and PostgreSQL RPCs; in-memory stores are permitted only under `tests/`.
- Never run `supabase db reset` against a linked staging or production project.

## Required checks

Run `npm run lint`, `npm run typecheck`, `npm run test`, and `npm run build` before committing. Validate migrations against a disposable Supabase database when Docker/Supabase CLI is available.
